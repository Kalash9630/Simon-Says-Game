# 🎮 Simon Says Game

A simple and interactive memory game built using **HTML, CSS, and JavaScript**. The game challenges players to remember and repeat an increasingly longer sequence of button flashes as they progress through different levels.

### 🚀 [Play Now](https://kalash9630.github.io/Simon-Says-Game/)

## 📌 About the Project

The Simon Says Game is a browser-based game inspired by the classic Simon memory game. At each level, the game displays a sequence of flashing colors, and the player must repeat the sequence in the correct order.

As the player progresses, the sequence gets longer, making the game more challenging. The game ends when the player selects the wrong button.

## ✨ Features

- 🎯 Interactive and engaging gameplay
- 🎨 Colorful buttons with flashing animations
- 🔢 Increasing difficulty with each level
- 🧠 Tests memory and concentration
- ⚡ Random sequence generation
- ❌ Game-over detection when an incorrect sequence is entered
- 🔄 Restart the game and try again

## 🛠️ Technologies Used

- **HTML5** – Structure of the game
- **CSS3** – Styling, layout, and animations
- **JavaScript** – Game logic, event handling, sequence generation, and level management

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in your browser.

4. Follow the on-screen instructions and start playing!

## 🎮 How to Play

1. Start the game by pressing any key on the keyboard.
2. Watch the sequence of flashing buttons carefully.
3. Click the buttons in the same order as they flashed.
4. Complete the sequence to advance to the next level.
5. Each new level adds another step to the sequence.
6. If you select the wrong button, the game ends. Try again to beat your previous level!
